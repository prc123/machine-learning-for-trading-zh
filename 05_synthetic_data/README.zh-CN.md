# 第 5 章：合成金融数据

交易研究的样本路径天然有限，而自适应搜索和多重检验很容易把回测表现推高到不可复现的水平。本章介绍经典模拟、生成式模型和评估框架，说明什么时候合成数据有用，什么时候只是放大过拟合。

## 学习目标

- 解释为什么交易研究受路径样本限制，以及自适应搜索和多重检验如何夸大回测表现。
- 使用 bootstrap、随机波动率等经典模拟作为可解释的合成数据基线。
- 根据数据结构和下游目标选择合成数据方法，包括时间序列和表格金融数据的学习型生成器。
- 使用 stylized facts、依赖结构和任务评估诊断生成数据，包括 Train-Synthetic-Test-Real 比较。
- 评估隐私和生成器特有风险，例如泄漏、偏差放大、对生成器过拟合以及场景新颖性不足。

## 章节脉络

### 5.1 量化研究者的困境

说明真实历史路径太少、市场会适应、且研究过程本身会制造选择偏差。

### 5.2 评估合成金融数据

建立保真度、实用性和隐私视角，并检查合成数据是否保留关键市场性质。

### 5.3 经典模拟基线

介绍统计模型、bootstrap 和随机波动率等可解释方法，作为复杂生成器的对照。

### 5.4 生成模型分类

按数据类型、时间依赖、条件结构和可控性组织生成式方法。

### 5.5 金融时间序列的 GAN

讨论生成对抗网络在时间序列上的建模难点、训练稳定性和评估方式。

### 5.6 金融时间序列的扩散模型

介绍扩散模型如何通过渐进去噪生成时间序列，以及其与 GAN 的权衡。

### 5.7 面向结构化金融数据的 LLM

讨论大语言模型在表格金融数据合成中的能力、限制和风险。

### 5.8 应用 Fidelity-Utility-Privacy 框架

把合成数据的评估从“看起来像”推进到“能否改善下游任务，同时控制隐私与泄漏风险”。
